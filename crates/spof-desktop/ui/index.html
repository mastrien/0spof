Celular

Sincronização com o app do celular

Leia o QR code no app do 0spof (Ajustes → Parear com o PC). Funciona só na rede de casa: o tráfego é HTTP protegido por token, então não exponha a porta na internet.

Gerar novo código desconecta todos os celulares pareados. No primeiro uso, o Windows pede para liberar o firewall em redes privadas.
